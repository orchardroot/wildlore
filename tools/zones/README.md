# Zone authoring scripts

The JSON in `data/zones/` is the source of truth the game loads. These scripts were used to lay out the
slice zones and are kept so layouts can be regenerated after big edits:

    python3 tools/zones/macclesfield.py tools/zones data/zones
    python3 tools/zones/routes.py tools/zones data/zones

Careful: regenerating overwrites hand edits (NPCs added by story scripts live in the JSON). After any zone
change run `tools/test.sh` (the validator checks warps, edges, spawns, buildings) and take a screenshot:

    godot --path . -- --boot=<zone>@<x>,<y> --shot=docs/screens/<name>.png

## Overseas (3.3, wave 33 agent 1)

RAF Brize Norton, Gibraltar and the Sovereign Base Areas are generated by `overseas_hub.py`, `overseas_gib.py` and
`overseas_cyprus.py` (shared helpers in `overseas_lib.py`), then `overseas_data.py` writes items, shops, quests, the
registry files in `data/overseas/`, creatures, quiz questions and the Cotswolds gate, and `overseas_recipes.py` draws
the creature recipes (run `tools/spritegen.gd` on them). Run each from the repo root, e.g.
`python3 tools/zones/overseas_hub.py`. The registry contract is in `core/overseas.gd`: any territory is one
`data/overseas/<id>.json` file, the departures board in RAF Brize Norton's terminal lists those whose `unlock_flag` is
set, and a territory's airfield or harbour brings you home with the story command `{"do": "overseas_home", "territory": "<id>"}`.
